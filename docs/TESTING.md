# 测试覆盖与边界

2026-10-18 的应用版本在 macOS Intel、Python 3.9.6、FFmpeg 8.1 上通过 54 项测试。测试包含任务排队、取消、重试、重启、子进程清理、帧时间轴、快速修补和输入规范化；不调用 ProPainter 模型作质量验收。

本地运行服务另以四种合成视频通过上传、选区、快速任务、轮询、下载和完整解码：普通 CFR、VFR、90 度旋转伴音频延迟、末帧长停留。还通过真实网页操作及下载哈希核对。测试素材约 2–3 秒、160×128 附近，不能推断长视频、高分辨率性能。

规范化测试覆盖 HEVC、SAR、奇数尺寸、视频非零起点、音频提前/延后、末帧停留及 241 帧 MOV 包时长异常。旋转方向、尾部画面、音频实际起音均做过独立核对。HDR、多音轨等按当前政策拒绝。

尚未完成跨浏览器/移动端矩阵、复杂格式特征的大规模组合、断电/睡眠恢复、内存与磁盘耗尽、长期耐久和多用户隔离测试。当前是本地研究工具，不承诺生产级可用性。

运行完整测试需要 FFmpeg 编解码器（含 libx264、libx265）及系统进程检查权限；受限沙箱禁止 ps 时，进程清理测试可能失败。ProPainter 源码子模块用于调度测试的哈希检查，模型权重不是单元测试必需品。
